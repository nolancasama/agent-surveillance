# Agent Surveillance

A single-mission 3D observation game for elementary English learners. Identify Lily in the market square, photograph useful evidence, then report her name, what she likes, and what she can do in spoken English.

## Run

```sh
npm install
npm run dev
```

Build with `npm run build` and run unit tests with `npm test`.

## Controls

- Drag, arrow keys, or WASD: pan the telephoto camera
- Mouse wheel, `+` / `-`, or Q / E: zoom
- Space or the round on-screen button: take a photo
- Esc: pause, resume, or finish surveillance
- `FINISH SURVEILLANCE`: review evidence when the mission is ready

The camera stays at the observation post; there is no player movement.
